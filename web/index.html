FlipFocus IoT

A physical cube to track focus time without using a phone.

Project Goal

Phones are distracting. FlipFocus is a physical cube. When you flip a specific side up, it starts a timer for that task on your dashboard. It uses an ESP32 and an accelerometer to detect which side is facing up.

● Physical interaction only
● Real-time cloud sync
● Long battery life

Cost Breakdown

Development Steps

🛠️

Step 1: Build

Connect MPU6050 to ESP32 via I2C pins. Add the battery and charging module.

🧠

Step 2: Logic

Write code to read gravity data. Map X, Y, Z values to 6 different cube faces.

🌐

Step 3: Connect

Setup WiFi on ESP32. Send the "Face ID" to Blynk or a custom server.

📈

Step 4: UI

Create the mobile app dashboard to show active timers and history.

Core Detection Logic

This code runs on the ESP32 to find which side is up:

void checkOrientation() {
  sensors_event_t a, g, t;
  mpu.getEvent(&a, &g, &t);

  if (a.acceleration.z > 9.5) state = "SIDE 1: WORK";
  else if (a.acceleration.z < -9.5) state = "SIDE 2: REST";
  else if (a.acceleration.y > 9.5) state = "SIDE 3: CODE";
  else if (a.acceleration.y < -9.5) state = "SIDE 4: READ";
  else if (a.acceleration.x > 9.5) state = "SIDE 5: DRAW";
  else if (a.acceleration.x < -9.5) state = "SIDE 6: MAIL";

  updateCloud(state);
}
